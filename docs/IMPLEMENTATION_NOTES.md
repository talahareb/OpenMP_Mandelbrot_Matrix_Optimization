# Implementation Notes and Experimental Methodology

## Coursework basis

The original Fall 2024 LAU CSC 447 Assignment 3 investigates two problems:

1. **Mandelbrot set rendering** using row-wise OpenMP parallelization and dynamic scheduling. The report contains the C pixel evaluation, PGM writer, and several program variants. It discusses thread-private variables and the effects of different thread counts.
2. **Matrix multiplication** using four strategies: `mm` (sequential), `mm_omp`, `mmT` (matrix B transposed), and `mmT_omp`. The report provides the benchmark `main()` and measured values for matrix sizes 256, 512, and 1024 and thread counts 1, 2, 4, and 8. The function bodies are *not* included in the submitted report.

The associated PDF is preserved as `reference/CSC447-Assignment3-redacted.pdf`.

## Repository code

- `mandelbrot/mandelbrot.c` adapts the core pixel algorithm and row-wise decomposition shown in the report. Improvements include thread-safe loop scoping, wall-clock timing, configurable dimensions/scheduling, a binary PGM writer, and deterministic pixel-hash verification.
- `matrix/matmul.c` **reconstructs** the four multiplication kernels from their described algorithms, rather than claiming to reproduce unprovided original kernel source. It also uses deterministic input matrices and independently checks every result against a sequential reference.
- The original assignment used `clock()` for Mandelbrot timings. This may measure summed CPU work rather than elapsed wall time across multiple threads. New timing uses `omp_get_wtime()` to compare elapsed time fairly.
- The source report includes a demonstration with an incorrectly shared nested-loop variable producing corrupted imagery. The public implementation uses a correct, thread-safe loop structure; results are checked across scheduling configurations.
- The reported historical timings are not mixed with the new measured CSVs, because compiler, hardware, timing approach, and experimental environment differ.

## Verification

From the repository root:

```bash
make
make test
```

The tests verify bitwise identity of serial/parallel Mandelbrot output and numerical agreement of all matrix multiplication variants with a sequential reference (tolerance: `1e-9 × (1 + |reference|)`).

## Measuring performance

```bash
python3 scripts/benchmark.py --threads 1 2 4 --matrix-sizes 128 256 384 --repeats 3
```

Results are recorded as individual trials under `benchmarks/`, with one CSV per experiment and a text file describing the machine. Charts are generated using median times. Matrix-transpose preparation is **included** in transposed timings. Mandelbrot file output is **excluded** from render timings to isolate compute work; all modes share the same output format.

Reported run: Linux container, AMD EPYC 9V74 CPU, GCC 14.2, up to four OpenMP threads. Small runs and shared-CPU effects can produce measurement variability; rerun on the target machine for reproducible performance claims.

## Visuals and source attribution

Images in `images/` are generated from the C renderer, using a presentation-only color map for the colored renderings. The underlying grayscale output is generated by the Mandelbrot program. The speedup and matrix charts are generated from recorded CSVs. No performance values are fabricated.

The coursework report, not this README, is the primary historical record of the LAU submission. This repository is the runnable, reproducible portfolio presentation of those experiments.
